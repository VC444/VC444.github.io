My first professional internship was at BlackBoxStocks, a fintech startup that offers real-time stock and options tools for traders. I worked here for 11 months, and since I was a part of the company for such a long time (for an internship), I was given the opportunity to work on many different things within BlackBoxStocks. My most notable contribution was planning and building a microservice using AWS Lambda and Amazon API Gateway that supports querying information about thousands of options contracts in the MongoDB database.
